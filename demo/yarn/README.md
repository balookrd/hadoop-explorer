# Демонстрационный стенд YARN Explorer

В данной папке находятся конфигурации и скрипты полностью автономного демонстрационного стенда с поддержкой **Kerberos (KDC)**, **OpenLDAP** и двух кластеров **Apache Hadoop YARN 3.3.6**.

## 🚀 Запуск и остановка

- Запуск: `./start-demo.sh` (или `docker compose up -d`)
- Остановка: `./stop-demo.sh` (или `docker compose down -v`)
