1. Management Zone (Control Plane) Dedicated VM / K8s
Клиентский доступ
💻 Web Console / UI HTTPS :8005
Svelte 5 SPA. Вход через Kerberos SPNEGO SSO в 1 клик или LDAP. Управление задачами, скоростью и DR.
УСТАНАВЛИВАЕТСЯ: Orchestrator JAR
⚙️ Replicator Orchestrator :8005 HTTP/REST
Java 21 LTS / Spring Boot 3.3.4 (Чистый координатор).
  • Cron Scheduler: планирование периодических задач
  • Agent Registry: учет адресов и heartbeat воркеров
  • Token Bucket: выдача квот полосы пропускания
  • Inotify Lease HA: координатор распределенной аренды HMS
  • Disaster Recovery Hub: Kill-Switch & Unfence
Хранилище состояния
🗄️ Metadata Storage :5432 PostgreSQL / H2
Спецификации задач (Jobs), подзадач (Tasks), история Job Runs и DR снимки.
⚠️ Инвариант: Оркестратор НЕ прокачивает файлы через себя! Работает строго как Control Plane.
2. ЦОД-1 Primary (Москва) DC1 Cluster • LAN 10/25G
УСТАНАВЛИВАЕТСЯ: Agent Daemon
🟢 Replicator Agent (DC1) :50051 gRPC
На узлах DataNode (Colocated) или Edge Gateway. Java 21 Netty демон.
  • Worker Loop: разбор пула подзадач из оркестратора
  • Fast Diff: in-memory diff по манифесту каталога
  • Tar-Streaming: упаковка мелких файлов < 1 МБ в RAM
  • Chunked Sender: стриминг блоков 4 МБ со сжатием Zstd
  • HMS CDC Streamer: опрос NOTIFICATION_LOG Hive
  • Rate Limiter: шейпинг по токенам Token Bucket
Hadoop Сервис
🏛️ HDFS NameNode (DC1) :8020/:9000 RPC
Листинг каталогов, метаданные блоков, снимки Snapshot-Diff.
Hadoop Сервис
💾 HDFS DataNodes (DC1) :9866 DTP / SASL
Прямое вычитывание блоков от имени UGI автора задачи (`doAs`).
Hadoop Сервис
🐝 Hive Metastore & KDC :9083 Thrift / :88

3. ЦОД-2 Standby / DR (Санкт-Петербург) DC2 Cluster • LAN 10/25G
УСТАНАВЛИВАЕТСЯ: Agent Daemon
🔵 Replicator Agent (DC2) :50051 gRPC
На узлах DataNode или Edge Gateway. Java 21 Netty демон (приемник).
  • Receiver Service: прием 4 МБ чанков, расчет хеша SHA-256
  • Tar Stream Extractor: распаковка мелких файлов прямо в HDFS
  • Zero-Staging Writer: запись в `._staging_` + атомарный rename
  • HMS DDL Applier: применение DDL (deleteData=false)
  • Staging Reaper: очистка сирот `._staging_*` старше 24ч
Hadoop Сервис
🏛️ HDFS NameNode (DC2) :8020/:9000 RPC
Создание staging файлов, атомарный rename в чистовой путь.
Hadoop Сервис
💾 HDFS DataNodes (DC2) :9866 DTP / SASL
Прямая запись блоков данных через Data Transfer Protocol.
Hadoop Сервис
🐝 Hive Metastore & KDC :9083 Thrift / :88
Накатывание схем и партиций; Kerberos keytab авторизация.
