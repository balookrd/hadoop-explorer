1. Management / Control Plane Dedicated Node / K8s
💻 Браузер оператора / DE HTTPS / 8005
Инженер данных, Администратор кластера, Дежурная смена ИТ.
  • Svelte 5 SPA интерфейс (Runes)
  • Вход через Kerberos SPNEGO SSO / LDAP
  • Управление задачами, скоростью и DR
⚙️ Replicator Orchestrator :8005 HTTP/REST
Java 21 LTS / Spring Boot 3.3.4 (Чистый координатор).
  • Cron Scheduler: планирование задач
  • Agent Registry: учет адресов воркеров
  • Token Bucket: выдача квот полосы
  • Inotify Lease HA: координатор схем HMS
  • Disaster Recovery Hub: Kill-Switch & Unfence
🗄️ Metadata Storage :5432 / File
PostgreSQL / H2 база данных задач оркестратора.
  • Спецификации задач (Jobs) и подзадач (Tasks)
  • Хронология запусков (Job Runs History)
  • Снимки состояний (DR Snapshots)
⚠️ Критический факт: Оркестратор НЕ прокачивает байты файлов через себя! Он работает строго как Control Plane.
2. ЦОД-1 (Primary — Москва) DC1 Cluster • LAN 25G
🟢 Replicator Agent (DC1) :50051 gRPC
Устанавливается на узлы DataNode или Edge/Gateway. Нативный Java 21 Netty демон.
  • Worker Loop: разбор пула задач из оркестратора
  • Tar-Streaming: упаковка файлов < 1 МБ на лету в RAM
  • Chunked Sender: стриминг блоков 4 МБ со сжатием Zstd
  • HMS CDC Streamer: опрос NOTIFICATION_LOG Hive
  • Rate Limiter: шейпинг по токенам Token Bucket
🏛️ HDFS NameNode (DC1) :9000 RPC / :9870
Манифесты каталогов, метаданные блоков, снимки Snapshot-Diff.
💾 HDFS DataNodes (DC1) :9866 DTP / SASL
Прямое вычитывание блоков данных от имени UGI Proxy User `doAs`.
🐝 Hive Metastore & KDC :9083 Thrift / :88 KDC
Thrift API, чтение DDL журнала; Kerberos keytab аутентификация.

3. ЦОД-2 (Standby / DR — Санкт-Петербург) DC2 Cluster • LAN 25G
🔵 Replicator Agent (DC2) :50051 gRPC
Устанавливается на узлы DataNode или Edge/Gateway. Нативный Java 21 Netty демон.
  • Receiver Service: прием 4 МБ чанков, хэш SHA-256
  • Tar Stream Extractor: распаковка стрима прямо в HDFS
  • Zero-Staging Writer: запись в `._staging_` + атомарный rename
  • HMS DDL Applier: применение DDL (deleteData=false)
  • HDFS Garbage Reaper: очистка сирот каждые 15 мин
🏛️ HDFS NameNode (DC2) :9000 RPC / :9870
Создание staging файлов, атомарное переименование в целевой путь.
💾 HDFS DataNodes (DC2) :9866 DTP / SASL
Прямая запись блоков данных через Data Transfer Protocol.
🐝 Hive Metastore & KDC :9083 Thrift / :88 KDC
Накатывание схем и партиций; Kerberos keytab авторизация.
🟣 Control Plane: Браузер ➔ Orchestrator (:8005 HTTP/S)  |  Agents ➔ Orchestrator (:8005 REST Heartbeat / Claim / Lease)
🟢 Data Plane WAN: Agent DC1 ➔ Agent DC2 (:50051 gRPC / HTTP/2, mTLS) — Прямая передача данных без захода в Оркестратор
🟠 Hadoop LAN: Агенты обращаются к локальным NameNode (:9000), DataNodes (:9866) и HMS (:9083) строго внутри своего ЦОД
